# Shamaj Unnayan Foundation

A responsive social-development foundation website with a mobile app-style section for community support, education, health, livelihoods, and volunteer engagement.

## Features
- Modern landing page for a social development foundation
- Impact and program sections
- Donation and partnership CTA
- Mobile app mockup section
- Responsive layout for desktop and mobile
- Animated quick stats

## Run locally
Open `index.html` in a browser, or serve the folder with a local static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Project purpose
This starter site is designed for a social development foundation focused on community upliftment, healthcare access, education, women empowerment, livelihood support, and climate resilience.
